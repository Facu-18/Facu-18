## Sobre mí

Desarrollador Fullstack con fuerte enfoque en **backend, arquitectura de software e integraciones**. Construyo APIs escalables, aplicaciones web y soluciones end-to-end aplicando principios **SOLID** y arquitectura modular.

Trabajo principalmente con **Node.js, TypeScript y NestJS**, desarrollo interfaces con **React / Next.js**, apps multiplataforma con **React Native + Expo**, y también me muevo dentro del ecosistema **.NET / C#**.

Actualmente profundizo en **microservicios, sistemas distribuidos y automatización con IA**.
